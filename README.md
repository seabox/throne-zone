# throne-zone
Simple movement tracking app to help decide what next action will be

The app is a single, standalone `index.html` file with no build step or dependencies.
Open it in a browser to preview it locally.

## GitHub Pages

In the repository's **Settings → Pages**, set **Source** to **GitHub Actions**.
After merging into `main`, the Pages workflow publishes the site automatically.
You can also run **Deploy GitHub Pages** manually from the **Actions** tab.

The published site is available at https://seabox.github.io/throne-zone/.
